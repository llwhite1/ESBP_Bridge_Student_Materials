## What you are learning

- Target: Design, mutate, summarize, and test a complete list-processing program from requirements alone.
- Evidence habit: original list, index, changed value, final list, summaries, and defended tests.
- Independence level: Independent construction; no planning questions and no algorithm steps.

## How to work

1. Complete the trace and explain the state evidence.
2. Diagnose the supplied defect and defend a repair.
3. Write one connected program that satisfies the complete specification.
4. Record tests, expected results, and a brief defense.
